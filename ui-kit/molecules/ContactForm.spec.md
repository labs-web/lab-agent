# Spécification : ContactForm

## Description
Formulaire visuel de contact.

## Structure Visuelle
- Input "Nom".
- Input "Email".
- Textarea "Message".
- Bouton "Envoyer".

## Éléments Requis
- [ ] Label pour chaque champ.
- [ ] Placeholder.
- [ ] Focus state (anneau de couleur).
- [ ] Bouton Submit full width ou aligné.

## Notes
- **Attention** : Pas de balise `<form action="...">` fonctionnelle PHP.
- Le bouton ne fait rien ou juste un `alert()` JS (facultatif).
- Styling Tailwind "Forms plugin" style (bordures grises, focus indigo).
