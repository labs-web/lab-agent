# Spécification : SkillBadge

## Description
Petit élément visuel pour afficher une compétence technique.

## Structure Visuelle
- Conteneur arrondi ou "pill".
- Icône (optionnelle).
- Nom de la compétence.

## Éléments Requis
- [ ] Conteneur background léger (Indigo-50).
- [ ] Texte couleur primary (Indigo-600).

## Données Attendues
- `name` : "Laravel"

## Notes
- Doit être très compact pour être utilisé dans une liste dense.
