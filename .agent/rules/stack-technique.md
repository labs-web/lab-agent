## Objectif
Garantir que tout code produit respecte strictement les choix technologiques et les versions définis pour ce projet.

## Directive
Pour toute décision concernant les langages, frameworks, librairies ou structure de projet, l'agent DOIT se référer à la ressource suivante :

@[.agent/resources/tech-stack.md]
