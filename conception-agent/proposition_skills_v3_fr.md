# Proposition de Nommage Simplifié (Français)

Voici 4 noms de skills conçus pour être immédiatement compréhensibles par un développeur junior, sans jargon complexe.

| Layer | Nouveau Nom (Proposé) | Rôle et Responsabilité                                                        |
| :---- | :-------------------- | :---------------------------------------------------------------------------- |
| **0** | `maquettage-html`     | Créer l'interface statique (HTML/CSS) pour validation visuelle.               |
| **1** | `gestion-requetes`    | Gérer les Routes et les Contrôleurs (Recevoir la demande -> Renvoyer la vue). |
| **2** | `logique-metier`      | Coder les Services et les règles de gestion (Calculs, "Cerveau").             |
| **3** | `gestion-donnees`     | Parler à la Base de Données (SQL, Repositories).                              |

Est-ce que ces noms plus directs vous conviennent mieux ?
